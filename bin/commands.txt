# omawin's commands: `omawin <group> <name> [arguments]`, like Omarchy's `omarchy`. The keys
# (config/glazewm/config.yaml), the system menu (default/launcher/menu.txt: `omawin <command>` actions), the
# dock and you in a terminal all use these names. `omawin help` lists them; bin/omawin.cs runs them.
#
#   <command> | <what it does, one line> | <action>
#
# Actions:
#   app <request>          hand the menu app (shell/menu-app/, always running) a request: instant
#   ask <request>          the same, for a request whose answer is printed (omawin setting get)
#   pwsh <script> [args]   a PowerShell script of this repo, path from the repo root; in your
#                          terminal when typed, hidden when run from a key
#   run <program> [args]   start a program
#   builtin <name> [args]  done by omawin.exe itself: launch-terminal, launch-project,
#                          launch-editor, terminal-here, terminal-warm, update-terminal, default;
#                          pkg by the compiled omawin-cli.exe beside it (src/cli/)
# {repo} in an action is this repo's folder; a pwsh script's path may start with {user}/, this
# account's own folder (docs/work.md: ~/omawin-account, or OMAWIN_USER_LAYER).
# Words typed after the command are added to the end.

# Fixing Windows (roadmap Phase 8): the answers Windows has and doesn't show. omawin-windows (src/windows/)
# does them in your terminal; the system menu's "This PC" rows open them in one.
who-has | Which programs hold a file or folder open, then close or end them: omawin who-has <path> (no path: the one on the clipboard, from Explorer's Copy as path) | run omawin-windows who-has

connections | Which apps are talking to the internet now, and to whom: omawin connections [app] | run omawin-windows connections
wifi share | The Wi-Fi you're on as a QR code a phone joins from; a saved one: omawin wifi share <network>; --show prints the password | run omawin-windows wifi-qr

mic | Every microphone at once: toggle (the default), mute, unmute, status; a red microphone in the bar while they're all muted (click it to unmute). No key until you choose one | app --mic
