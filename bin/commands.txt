# omawin's commands: `omawin <group> <name> [arguments]`, like Omarchy's `omarchy`. The keys
# (config/glazewm/config.yaml), the system menu (default/launcher/menu.txt: `omawin <command>` actions), the
# dock and you in a terminal all use these names. `omawin help` lists them; bin/omawin.cs runs them.
#
#   <command> | <what it does, one line> | <action>
#
# Actions:
#   app <request>          hand the menu app (shell/menu-app/, always running) a request: instant
#   pwsh <script> [args]   a PowerShell script of this repo, path from the repo root; in your
#                          terminal when typed, hidden when run from a key
#   run <program> [args]   start a program
#   builtin <name> [args]  done by omawin.exe itself: launch-terminal, launch-project,
#                          launch-editor, terminal-here, terminal-warm, update-terminal, default
# {repo} in an action is this repo's folder; a pwsh script's path may start with {user}/, this
# account's own folder (docs/work.md: ~/omawin-account, or OMAWIN_USER_LAYER).
# Words typed after the command are added to the end.

launcher | The launcher (Win+Space); with a page name, that page: projects, clipboard, localhost, reports, keys, audio (the sound: speakers, what plays on them, microphones), quick (Quick settings: the switches above the sound), packages, about | app --launcher
files | The file finder (Win+F) | app --files
menu | The system menu (Win+Alt+Space); with a row id, that submenu: omawin menu install | app --open

capture screenshot | Screenshot (Win+Shift+S): drag a region, click a window, Enter for everything | app --snip
capture text | Text from the screen (Win+Shift+T): drag over it, its text is copied | app --snip text

theme set | Apply a theme: omawin theme set gruvbox [-Background village-square] | pwsh themes/set-theme.ps1
theme next-background | The current theme's next background (Win+Ctrl+Space) | pwsh themes/set-theme.ps1 -NextBackground
theme backgrounds | The background picker: a grid of the current theme's pictures, Enter sets one, Tab shows another theme's; or a theme's: omawin theme backgrounds gruvbox | app --open style.backgrounds
theme background | One of the current theme's backgrounds, by name or part of it: omawin theme background village-square | pwsh themes/set-theme.ps1 -Background
theme add | Install a community theme by name (omawin theme search), at the commit the index checked, or any theme from its git link; applies it | pwsh themes/theme.ps1 add
theme search | Community themes matching every word (name, author, light, dark), with their repos: omawin theme search nord | pwsh themes/theme.ps1 search
theme preview | A community theme across the desktop for a moment, nothing installed: omawin theme preview <name>; omawin theme preview off puts yours back (the picker's Community chip does this as you move) | pwsh themes/theme.ps1 preview
theme install | The same as theme add (the older name): a theme by name or git link, like Omarchy's | pwsh themes/theme.ps1 install
theme update | Update installed themes, or one: omawin theme update <name>; shows what changed in each repo and asks first (-Yes doesn't) | pwsh themes/theme.ps1 update
theme remove | Remove an installed theme: omawin theme remove <name> (asks which if left out) | pwsh themes/theme.ps1 remove
theme list | Every theme, Omarchy's and installed ones; * is the one in use | pwsh themes/theme.ps1 list
theme browse | Omarchy's page of community themes (omarchy.org/themes) | pwsh themes/theme.ps1 browse
theme import | Remake this repo's themes from Omarchy's own (for omawin's maintainers; rerun for new ones) | pwsh themes/import-omarchy.ps1
theme lockscreen | The lock screen's next background | pwsh themes/set-lockscreen.ps1 -Next

terminal here | A terminal in the focused window's folder (Win+Enter) | builtin terminal-here
workspace rename | Name the current workspace (Alt+N) | builtin launch-terminal --title rename -- pwsh -NoLogo -NoProfile -File "{repo}\default\launcher\rename-workspace.ps1"

launch terminal | A terminal, in the default terminal: [--dir <folder>] [--title <title>] [--wsl: in your Linux] [-- <command>] | builtin launch-terminal
launch project | A project window (default/launcher/project-tabs.txt): <folder> [--wsl] | builtin launch-project
launch editor | A file or folder in the default editor | builtin launch-editor
default | What omawin opens things with (bin/defaults.txt): omawin default terminal wt picks one; omawin default linux arch (or ubuntu), the Linux in WSL | builtin default

restart glazewm | Fill the theme into GlazeWM's config and reload it (Alt+Shift+R) | pwsh themes/render.ps1 -Reload
restart menu | Rebuild and restart the menu app (after editing shell/menu-app/) | pwsh shell/menu-app/build.ps1
restart music | Rebuild the music player (after editing src/music/); the bar picks it up by itself | pwsh src/music/build.ps1

music | The music, podcast and radio player in the bar: open (Win+M), add <url>, add podcasts <url>, add radio <url> [name], add suno <url>, suno-create (Suno's create page, to make a song), list, toggle, next, prev, rate <1-5>, station [songs or jams] (src/music/) | run omawin-music
agent listen | Talk to omawin's agent (Ctrl+Win+H): it listens; a second press sends what you said to a herdr session on workspace 9, where it does it live (quick changes to omawin, music, issues) | run omawin-listen.exe
agent open | Show omawin's agent: its herdr session on workspace 9, with OpenCode's service in the first tab and a tab per request | pwsh src/agent/open.ps1
agent start | Start omawin's agent's herdr session in the background, with OpenCode's service in it, so requests only attach (GlazeWM does this at login) | pwsh src/agent/start.ps1
agent cancel | Stop listening for the agent and drop what was said | run omawin-listen.exe cancel
agent ask | Ask omawin's agent, typed: it does it in the background (OpenCode or Claude Code, src/agent/config.json) it adds music and podcasts, opens issues, starts work in a worktree (docs/agent.md) | pwsh src/agent/ask.ps1

account new | Start this Windows account's own folder, ~/omawin-account (docs/work.md): git identity, empty launcher / shell files, a git repo; -Repo <name> keeps it in a private GitHub repo | pwsh bin/account-new.ps1
shared | The PC's shared folder (docs/work.md): yours in every account, which every account reads and only its owner changes; -From owner/name starts it from a backup | pwsh bin/shared.ps1
shared backup | Commit what changed in the shared folder and push it to its private backup repo (-Repo <name> the first time) | pwsh bin/shared.ps1 backup
claude sync | Claude Code's rules, skills, settings and plugins from the shared folder and this account's (docs/work.md); install runs it | pwsh bin/claude-sync.ps1

reports index | Refresh the Reports list now (this account's reports script; docs/work.md) | pwsh {user}/reports/reports.ps1 -Index

update | Pull this repo, relink, run new migrations | pwsh bin/update.ps1
update terminal | The default terminal's latest release (noctty: its latest release; Windows Terminal: winget) | builtin update-terminal
migrate | Run the migrations this PC hasn't run yet | pwsh bin/migrate.ps1
profile terminal | Measure what opening a terminal costs, step by step (-Runs 5, -Video file.mp4) | pwsh bin/profile-terminal.ps1
profile menu | Measure a menu key to its first frame, per surface (-Surface launcher, menu or files; -Runs 10), or typing in the launcher to the list on screen (-Typing); -Hand for runs pressed by you | pwsh bin/profile-menu.ps1
profile login | How long after you signed in each part of the desktop was up (-Arm adds timing marks from the next sign-in) | pwsh bin/profile-login.ps1
profile ram | What's using the memory and the processor, the whole PC by group, memory in use apart from cached, omawin's desktop against its 600 MB (-Save keeps a history and shows what changed, -Quick skips the processor, -Json for agents) | pwsh bin/profile-ram.ps1
check | Health check: is everything in place and running | pwsh bin/check.ps1
path | Your PATH and Windows': empty, missing and duplicate entries, and which node / python / git … runs and why (more to look up: omawin path rg); omawin path fix cleans yours, omawin path undo puts it back | run omawin-path.exe
install | Install and link everything (-LinkOnly: only relink; -Step <name>: one step) | pwsh install.ps1
no-ads | Windows' ads off, and the PC maker's upsells (Lenovo, McAfee, Adobe, when found; asks for admin) | pwsh bin/no-ads.ps1
dev install | A development environment, as Omarchy's (mise where Windows allows, else each one's own installer): ruby, docker-db, node, bun, deno, go, php, laravel, symfony, python, elixir, phoenix, zig, rust, java, dotnet, ocaml, clojure, scala; -Check [name] says what's installed | pwsh bin/install-dev-env.ps1
dev remove | Take a development environment away again: omawin dev remove node | pwsh bin/remove-dev-env.ps1
pkg find | The package picker, in the launcher: winget, Chocolatey or Scoop (Tab), fuzzy found, Enter installs; Ctrl+Space picks several | app --launcher packages
pkg install |Any of winget's ~16,000 packages, fuzzy found (fzf, with a preview) and installed; Tab picks several: omawin pkg install [query] | pwsh bin/pkg-install.ps1
pkg remove | What winget installed here, fuzzy found and uninstalled; Tab picks several | pwsh bin/pkg-remove.ps1
pkg index | winget's catalog read off the PC into %LOCALAPPDATA%\launcher\winget-index.tsv (pkg install does it when it changed): its path | pwsh bin/pkg-index.ps1
pkg update | Update packages each through where it came from (the tools bundle, winget, Scoop, Chocolatey, mise, npm, its installer): omawin pkg update [name], -List shows them | pwsh bin/pkg-update.ps1
preset list |The presets: opt-in groups of tools on top of the core (install/packages.ps1), the picked ones marked | pwsh bin/preset.ps1 list
preset add | Pick a preset and install it now: omawin preset add data | pwsh bin/preset.ps1 add
preset remove | Unpick a preset (what it installed stays): omawin preset remove data | pwsh bin/preset.ps1 remove
plugin list | The plugins (shell/plugins, Omarchy's format), the ones on marked | pwsh bin/preset.ps1 plugins
plugin add | Turn a plugin on and install its programs: omawin plugin add music | pwsh bin/preset.ps1 plugin-add
plugin remove | Turn a plugin off (what it installed stays): omawin plugin remove music | pwsh bin/preset.ps1 plugin-remove

start glazewm | Start GlazeWM once Windows' taskbar is up, again if it crashes at start (the sign-in task runs this) | builtin start-glazewm
glazewm admin | Manage admin windows too: omawin's GlazeWM for the whole PC, signed on this PC; says what changes, then one admin prompt | pwsh install/glazewm-fork.ps1
glazewm admin-off | Back to the per-user GlazeWM (or the official one you had before): one admin prompt | pwsh install/glazewm-fork.ps1 -Restore
