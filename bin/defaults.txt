# What omawin opens things with, like Omarchy's defaults. `omawin default <kind> <name>` picks
# one for this PC (installed first if it's missing); `omawin default` shows the picks. The
# first row of a kind is the default when nothing was picked. The pick is per PC, in
# %LOCALAPPDATA%\launcher\defaults\<kind>.
#
#   <kind> | <name> | <label> | <winget id, or a script of this repo that installs it> | <program>
#
# Everything that opens a terminal or an editor goes through `omawin launch terminal|project|editor`,
# which knows how to drive each of these (bin/omawin.cs).

terminal | noctty | noctty (Ghostty for Windows) | bin/noctty.ps1 | noctty.exe
terminal | wt | Windows Terminal | Microsoft.WindowsTerminal | wt.exe

editor | nvim | Neovim (in the terminal) | Neovim.Neovim | nvim.exe
editor | neovide | Neovide | Neovide.Neovide | neovide.exe
editor | code | VS Code | Microsoft.VisualStudioCode | code.cmd

agent | opencode | OpenCode | SST.opencode | opencode.exe
agent | claude | Claude Code | Anthropic.ClaudeCode | claude.exe

# Linux in WSL (the wsl preset), what `--wsl` opens. The program is the distro's WSL name; picking
# one sets it up (wsl/install.ps1). Arch gets Omarchy's package repositories (wsl/setup.sh).
linux | arch | Arch Linux, with Omarchy's packages | wsl/install.ps1 | archlinux
linux | ubuntu | Ubuntu | wsl/install.ps1 | Ubuntu
