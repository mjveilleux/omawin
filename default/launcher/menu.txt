# The system menu (launcher -> Menu, or Win+Alt+Space), after Omarchy's menu: install and
# remove software, edit configs, update, power. The menu app (shell/menu-app/) draws it and does
# most rows itself; task, winget and choco rows (and Remove) it hands to menu.ps1 -Run <id>.
#
#   <id> | <icon> | <label> | <action>
#
# Dotted ids make the tree: install.development.rust sits under Install > Development. A row
# without an action is a submenu. Rows show in this file's order. Actions:
#   winget <id>      install that winget package; rows already installed show a ✓ and can't
#                    be picked. Remove lists the installed ones by itself (no remove.* rows needed).
#   choco <id>       the same through Chocolatey (asks for admin)
#   task <command>   PowerShell, run in a small terminal window you can watch
#   edit <path>      open a file or folder in Neovim (~ is your home folder)
#   run <command>    start a program, a URL or a settings page, like items.txt
#   omawin <command> one of omawin's commands (bin/commands.txt), hidden
#   @<page>          one of the launcher's pages (@keys, @clipboard, @localhost, ...)
#   settings <area>  Windows' settings of one area, each switched in place (default/launcher/settings.txt:
#                    look, explorer, privacy, input, system, display, connections, sound, developer);
#                    settings undo puts the last change back, settings admin applies the queued admin ones
#   themes           the theme picker (themes/*.json and installed themes, applied by
#                    themes/set-theme.ps1)
#   backgrounds      the background picker: a grid of a theme's pictures (set by
#                    themes/set-theme.ps1 -Background)
#   plugins          the plugin gallery: omawin's plugins and Omarchy's marketplace, on or
#                    off with Enter (omawin plugin add|remove)
# A ! in front of the action asks before doing it.
