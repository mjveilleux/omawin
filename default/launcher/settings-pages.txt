# Settings pages, consoles and classic dialogs, found by the system menu's search (roadmap 1B.1,
# plans/02-settings-and-one-search.md §10). Always searched, beside Windows' own settings index
# (its AllSystemSettings file, read on the PC) and all there is when that can't be read; it also
# holds what Windows' index doesn't list: the admin consoles and the dialogs people still need.
# Layered like items.txt: the shared folder's and this account's launcher/settings-pages.txt add theirs.
#   uri | name | page | keywords
# The uri is an ms-settings: page (Microsoft's documented list), a console or a program and its arguments.
