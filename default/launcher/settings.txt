# Windows settings omawin reads and changes itself (plans/02-settings-and-one-search.md §1).
#   id | icon | name | keywords | kind | how | notes
# Layered: the shared folder's and this account's launcher/settings.txt add lines or replace one
# by id. "check" in notes: not yet verified on a PC, hidden from users.
#
# how, by verb (shell/menu-app/Settings/):
#   reg <HIVE\key\value> <dword|qword|sz|expand_sz> on= off= | values= | range= [default=] [broadcast=<area>]
#       [refresh-explorer] [restart-explorer]     a registry value; off=- deletes it (Windows' default)
#       a switch may join values with " + " (reg A … + reg B …): set together, off when all are off
#   spi <name>        SystemParametersInfo (Switches.cs): animations mouse-accel pointer-speed key-repeat
#                     key-delay sticky-hotkey swap-buttons scroll-lines double-click drag-full-windows
#                     font-smoothing snap focus-follows-mouse menu-delay min-animate filter-hotkey toggle-hotkey
#   powercfg <name> <ac|dc|both>   the active power plan (Switches.cs): screen-off sleep hibernate-after
#                     lid power-button wake-timers standby-network; minutes for the timeouts, 0 is never
#   builtin <name>    code (Builtins.cs): wifi bluetooth airplane power-mode brightness desktop-icons
#                     refresh-rate hdr proxy hotspot audio-output audio-input restart-explorer classic-menu
#                     caps-lock copilot-key (the keyboard hook's, KeyHook.cs),
#                     disabled-hotkeys startup-item <app> layout-hotkey folder-type-general case-sensitive,
#                     and the admin ones (read here, set in the one prompt by bin/settings-admin.ps1)
#                     hibernate sudo windows-feature <feature> service <name> on=<mode> off=<mode>
#                     ssh-agent utf8 ai-paint firewall-dev
#   link <uri or program>   opens a page; omawin <command>   one of omawin's commands
# notes: admin (one prompt for all of them, roadmap 2.9), signout, restart, minBuild=, maxBuild=, check.
# CI sets and restores every reg, spi and powercfg line on a Windows runner (.github/workflows/test.yml).
