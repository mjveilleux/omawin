# omawin pkg's names (src/cli/Pkg): one name for one thing, and its id in each package manager,
# so `omawin pkg install ripgrep` means the same program whichever manager puts it in.
#
#   <name> | <winget id> | <scoop app> | <chocolatey id> | <mise tool> | <arch package> | <apt package> | <command> | <prefer>
#
#   -        that manager doesn't have it
#   command  the program it puts on the PATH (omawin pkg info says which copy runs)
#   prefer   omawin's own pick of manager for it (languages through mise); your pin
#            (omawin pkg move) comes first, your order (omawin pkg prefer) after it
#
# The tools bundle's tools (install/tools.txt) are bundled under the same names. A name that isn't
# here is looked up in each manager's catalogue (omawin pkg install <id> --from <manager> to say).
