# Launcher items (Win+Space; the native launcher, menu-app/), listed before every installed app:
#     <icon> | <name> | <command>
# <command> is a program and its arguments (env vars like %LOCALAPPDATA% expand), a URL or a
# settings page, or one of the launcher's own pages:
#     @projects   git repos on Windows and in WSL, opened as the project's herdr session (shell | nvim | claude | opencode)
#     @localhost  web servers running on this PC (and in WSL) + favorite sites (sites.txt)
#     @clipboard  what you've copied, newest first; Enter pastes it (Win+Shift+V)
#     @reports    reports from your own folders and shares (needs a reports script in your account folder: docs/work.md)
#     @keys       the shortcuts cheat sheet (keys.txt)
#     @audio      speakers and microphones, what plays on each, their volume (Win+A)
#     @quick      Quick settings: Wi-Fi, Bluetooth, brightness, power mode, night light, do not
#                 disturb, battery — and the sound below them
#     @files      the file finder (Win+F)
#     @menu       the system menu (Win+Alt+Space)
#     @vpn <name> connect a Windows VPN connection (or disconnect it)
# The shared folder's and this account's launcher/items.txt (docs/work.md), where there are any, add theirs after these
# (docs/work.md).
# Icons are Nerd Font glyphs (https://www.nerdfonts.com/cheat-sheet). Order here = order shown.
