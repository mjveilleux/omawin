# The dock: three open points

**Context.** The bottom dock is built (manual/07-bar-and-dock.md): Start, Search, Settings,
Explorer, the launcher and the system menu on the left; every open window, grouped by
workspace, in the middle; quick settings, notifications and show desktop on the right.

**Open points.**
- Only the current workspace's windows instead of all of them?
- Pinned apps (always shown, click to open) like the Windows taskbar's? Which ones?
- Should the dock auto-hide too (it then needs a hover strip at the bottom), or stay?

**Default.** All windows, no pinned apps, always shown.
