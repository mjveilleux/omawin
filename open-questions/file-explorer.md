# What should "better files" mean first?

**Question:** the maintainer likes their file explorer today and would like it better, without a clear "how". Which of the roadmap's file ideas ([docs/roadmap.md](../docs/roadmap.md), phase 5) comes first, and is "my file explorer" Windows Explorer or the Win+F finder?

**Options:**
1. **Explorer's developer defaults** (extensions and hidden files shown, opens to home, full path in the title, no Gallery / recommendations, dark / light from the theme), as tweaks with undo.
2. **Win+F grows into a finder you act from**: Space to preview, Ctrl+Enter to show in Explorer, open the folder in the terminal or editor, copy the path.
3. **A files default** (`omawin default files`), with a key for "files here" from the terminal.
4. **yazi** in the terminal, themed.

**Default:** 1 then 2: small, safe, and every day; 3 and 4 after.
